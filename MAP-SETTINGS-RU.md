# Настройки анимации Hero

Основной файл: `src/data/map-animation-settings.json`.
Все параметры с окончанием Ms — миллисекунды: 1000 = 1 секунда. Длительности задавайте положительными числами; прозрачность — от 0 до 1. В JSON используйте точку для дробной части.

| Параметр | Значение | Что меняет |
|---|---:|---|
| drawDurationMs | 5000 | Время прорисовки контуров |
| fillDurationMs | 3000 | Время проявления заливки после контуров |
| tipFadeDurationMs | 550 | Угасание светящихся концов линий |
| islandStartMs | 1200 | Когда начинают появляться острова, от начала контуров |
| islandStaggerMs | 2200 | Диапазон задержек появления островов |
| islandStepMs | 19 | Шаг задержки между островами |
| flashDurationMs | 1200 | Полная длительность вспышки города |
| cityIntervalMs | 1000 | Интервал между началами вспышек |
| labelFadeDurationMs | 220 | Время проявления точки и подписи |
| flashIgnitionMs | 35 | Время выхода вспышки на начальную яркость |
| shimmerDurationMs | 5200 | Длительность полного цикла мерцания |
| shimmerMinOpacity | 0.7 | Нижняя яркость мерцания: 0.7 = 70% от обычной |
| landOpacity | 0.4 | Плотность заливки суши |
| labelFontSize | 7.5 | Единый размер шрифта в координатах SVG |
| labelGap | 4 | Базовый отступ подписи от точки |

Перекрытие вспышек = flashDurationMs − cityIntervalMs. Сейчас 1200 − 1000 = 200 мс. Если хотите перекрытие, оставляйте интервал меньше длительности вспышки. labelFadeDurationMs лучше не делать больше flashDurationMs.

Общее время = drawDurationMs + fillDurationMs + (число городов − 1) × cityIntervalMs + flashDurationMs. Сейчас 66 городов, то есть 74.2 секунды активного воспроизведения. Мерцание начинается только после окончания последней вспышки. При скрытой вкладке или Hero вне экрана показ городов приостанавливается.

## Закрепление подписей

Файл `src/data/map-capitals.json`, раздел `labelPositions`.
Формат: [направление X, направление Y, дополнительный сдвиг X, дополнительный сдвиг Y]. Последние два значения необязательны.

- X: −1 слева, 0 по центру, 1 справа.
- Y: −1 сверху, 0 по центру, 1 снизу.
- Дополнительные сдвиги: единицы SVG; положительный X вправо, положительный Y вниз.

Примеры:

```json
"Kyiv": [1, 0],
"Warsaw": [1, 0, 0, -3],
"Berlin": [1, 0, 0, -3],
"Vienna": [1, 0, 0, 3],
"Amsterdam": [0, -1]
```

Закреплённые подписи не перемещаются алгоритмом. Остальные подписи стараются обходить их. После изменения размера шрифта стоит проверить плотные участки: закрепления могут пересечься.

## Как посмотреть изменения

При запущенном `npm run dev` сохраните JSON и обновите страницу для перезапуска анимации. Чтобы обновить собранный сайт, выполните `npm run build` из папки сайта. После изменения списка городов выполните `npm run prepare:map` или полную сборку: точки создаются при генерации SVG.

Не редактируйте `src/generated/world.svg` или файлы в `dist`: они перезаписываются сборкой. Старые значения в `Map animation/index.html` относятся к исходному референсу, а не к текущей анимации сайта.

Дополнительное оформление: размеры и цвета вспышки — `scripts/map-cities.mjs` (city-halo, city-bloom, city-core); цвет контуров и заливки, затемнение за текстом — `src/styles/global.css` (--coast, --land-fill, .hero-content::before). Форма угасания вспышки — `src/scripts/map-animation.ts` (Math.pow). Форма цикла мерцания — `scripts/prepare-world-map.mjs` (@keyframes coastline-shimmer); нижняя яркость берётся из основного JSON.
